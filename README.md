# 🍔 Munch - Full Stack Food Ordering Application

A modern full-stack food ordering web application built with React, Node.js, Express, Prisma ORM, and MySQL.

## 🚀 Live Demo

🌐 Frontend: https://munch-app-five.vercel.app

🔗 Backend API: https://munch-app-backend.onrender.com

## 📂 GitHub Repository

https://github.com/Amit01verma/Munch-App

---

# ✨ Features

- User Registration & Login
- JWT Authentication
- Browse Food Categories
- Search Food Items
- Add to Cart
- Update Cart Quantity
- Place Orders
- Responsive UI
- Cloud Database
- Fully Deployed Application

---

# 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Axios
- CSS

### Backend
- Node.js
- Express.js
- Prisma ORM
- JWT Authentication
- Bcrypt

### Database
- MySQL (Aiven Cloud)

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: Aiven Cloud

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Amit01verma/Munch-App.git
```

## Install Frontend

```bash
cd client
npm install
npm run dev
```

## Install Backend

```bash
cd server
npm install
npm start
```

---

# 🔐 Environment Variables

Create a `.env` file inside the **server** folder.

```env
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
PORT=5000
```
